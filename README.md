# 🔐 Password Strength Analyzer

أداة بسيطة وقوية بلغة Python لتحليل قوة كلمات السر وتقييم مستوى أمانها.

## ✨ المميزات

- ✅ **فحص الطول والتنوع**: يحلل طول كلمة السر وتنوع الأحرف (صغيرة، كبيرة، أرقام، رموز خاصة)
- 🧮 **حساب الإنتروبي (Entropy)**: يقيس درجة العشوائية بوحدة البت
- ⏱️ **تقدير وقت الكسر**: يحسب الوقت المتوقع لكسر كلمة السر بهجوم قوة غاشمة (Brute Force)
- 🚨 **فحص التسريبات**: يتحقق من كلمة السر عبر [HaveIBeenPwned API](https://haveibeenpwned.com/) باستخدام تقنية k-Anonymity (بدون إرسال كلمة السر كاملة)
- 🔍 **كشف الكلمات الشائعة**: يكشف إذا كانت كلمة السر من القوائم الأكثر استخداماً
- 💡 **توصيات للتحسين**: يقدم اقتراحات واضحة لتعزيز كلمة السر
- 📊 **نظام تقييم من 100**: نتيجة رقمية واضحة مع تصنيف لوني

## 🔬 كيف يعمل؟

### حساب الإنتروبي
يُحسب الإنتروبي بالصيغة:
```
Entropy = Length × log₂(Charset Size)
```
- كل كلمة سر بإنتروبي **أقل من 40 بت** تُعتبر ضعيفة
- الإنتروبي **80+ بت** يُعتبر قوياً جداً

### فحص HaveIBeenPwned
يستخدم البرنامج تقنية **k-Anonymity**:
1. يحسب هاش SHA-1 لكلمة السر
2. يرسل فقط أول 5 أحرف من الهاش للـ API
3. يقارن محلياً - كلمة السر لا تغادر جهازك أبداً ✓

## 🛠️ الاستخدام البرمجي

```python
from password_analyzer import PasswordAnalyzer

analyzer = PasswordAnalyzer("MyPassword123!")
result = analyzer.analyze()

print(f"Score: {result['score']}/100")
print(f"Strength: {result['strength']}")
print(f"Entropy: {result['entropy_bits']} bits")
```
